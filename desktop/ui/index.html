Settings

Chat models get the earlier questions as conversation turns, with the SQL that answered them. "All that fit" uses as much of the chat as fits in about half the model's context window (asked from Ollama, Claude and Gemini; 20 questions otherwise). CodeS was trained on single questions, so it gets the previous question and the follow-up combined — not measured.
The first 5 rows of each earlier answer, so a follow-up like "which of those is the oldest?" can refer to them. Sending them to a cloud service shares your data with it.

Percentages were measured on the Spider benchmark's 1,034 questions with CodeS-1B on SQLite. Other models use the same agreement rules, but their accuracy is not measured; nor is PostgreSQL or MySQL.
